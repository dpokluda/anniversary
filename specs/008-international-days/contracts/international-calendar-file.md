# Contract: International Days calendar file

The calendar this feature added, as built on 2026-10-10: `calendars/Anniversary.Calendar.International.json`,
generated by `calendars/Build-Calendars.ps1` and embedded in the app as `Anniversary.Calendar.International.json`.
Format: [docs/spec.md](../../../docs/spec.md) 5.1 (metadata from 003, rule keys from 006); data model:
[data-model.md](../data-model.md).

## Metadata

| Key | Value |
|---|---|
| `name` | `International Days` |
| `locale` | absent: the calendar belongs to no region |
| `source` | `United Nations list of international days (https://www.un.org/en/observances/list-days-weeks, as of 10 October 2026), plus fun days kept by tradition` |
| `license` | `MIT, Copyright (c) David Pokluda (part of Anniversary; see LICENSE)` |
| `calendar` | 61 entries: 58 `MM-dd` keys and 3 rule keys (below) |

The file is UTF-8 without a byte order mark, indented by two spaces, with the keys in ordinal order (so `05-31` comes
before `05-Sat-2`). `calendars/THIRD-PARTY-NOTICES.md` is unchanged; the license is the app's own.

## Content rules

- **56 UN days** chosen from the
  [United Nations list of international days](https://www.un.org/en/observances/list-days-weeks) as of 10 October
  2026 (239 days then), under the UN's names. Two names are shortened: International Holocaust Remembrance Day and
  International Volunteer Day.
- **5 fun days** kept by tradition: Pi Day, Star Wars Day, World Emoji Day, Talk Like a Pirate Day and International
  Beer Day.
- **Days that move** use rule keys: `05-Sat-2` and `10-Sat-2` (World Migratory Bird Day, the second Saturday of May and
  of October) and `08-Fri-1` (International Beer Day, the first Friday of August).
- **Two days on one date** share one value, joined with ", " (`03-21`).
- **Not included**: the rest of the UN list, its weeks (for example World Space Week) and Vesak (a full-moon day);
  International Day of Mathematics (14 March), which isn't on the UN list; anything from commercial "national day"
  lists, which are copyrighted.

## How the app shows it

- The line under the date shows the day's `MM-dd` entry first, then each rule that falls on the day, joined with ", "
  (spec 6.3): 10 October 2026 reads `World Mental Health Day, World Migratory Bird Day`. A day without an entry shows
  nothing.
- Next N days lists the names of the coming days and Find… searches them, as for any calendar (spec 6.1, 6.2).
- Loading the shipped file gives no warnings.
- Without a `locale`, the calendar is never the starting calendar for an OS region (spec 5.7); it is chosen in the
  Calendar menu ([calendar-menu.md](calendar-menu.md)).

## Generation (`calendars/Build-Calendars.ps1`)

- **Input**: the ordered table `$international` (key = value, with the source as a comment), written in the script.
- **Call**: `Write-Calendar 'International' 'International Days' '' {source} {license} $international -Holidays`.
  The empty locale makes `Write-Calendar` leave out the `locale` line (new in this feature; before, the line was
  always written). `-Holidays` skips the full-year check for name-day calendars.
- **Checks** (as for every calendar): each key is a valid `MM-dd` or rule key, no value is empty, and the written file
  parses back with the same number of entries; otherwise the script stops with an error.
- **Output**: `calendars/Anniversary.Calendar.International.json` and the report line
  `International  61 entries  International Days` (the file-name column was widened from 12 to 13 characters for
  "International"). The other 11 calendar files are written again and don't change.
- **Embedding**: the existing `<EmbeddedResource Include="..\calendars\Anniversary.Calendar.*.json" …>` in
  `Anniversary.Shared/Anniversary.Shared.csproj` picks the new file up; no project change.
